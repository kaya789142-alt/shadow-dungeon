# 暗影地下城 Shadow Dungeon V2.2

一款繁體中文、斜俯視像素風的單人即時戰鬥 RPG。遠古王國艾瑟蘭的地下封印正在瓦解。從燼燈村出發，狩獵魔物、探索秘徑、蒐集裝備，解除七處區域封印並挑戰黑暗魔王。

## 安裝與啟動

需要 Node.js 22.16 以上，建議使用 Node.js 24。

```sh
npm ci
npm run dev
```

在瀏覽器開啟 Vite 顯示的網址（預設通訊埠 5173）。開發伺服器監聽所有介面。若從同一區域網路的手機測試，使用電腦的區網位址及相同通訊埠。iPhone 與 iPad 可從 Safari 的分享選單加入主畫面。安裝與離線功能使用正式版，需由 HTTPS 或本機安全來源提供。

## 開始遊玩

1. 建立冒險者，從騎士、妖精、法師、暗影刺客、聖騎士選擇職業。
2. 開啟背包，穿戴起始武器與盔甲。完成村莊教學後，可在任務簿領取獎勵。
3. 從右上角小地圖傳送到幽暗森林，或走到村莊東側的傳送門。鎖定魔物，擊敗後拾取戰利品。
4. 在燼燈村購買藥水與卷軸、鑑定裝備、強化裝備，或到技能導師修習技能。更高等級會解鎖後續區域。
5. 對抗魔王時，離開地面的紅色預警區。也可用回城卷軸回到燼燈村補給。

| 功能 | 操作 |
| --- | --- |
| 移動 | WASD、方向鍵、點擊地面或觸控搖桿。按住 Shift 或將搖桿推至外圈可奔跑 |
| 鎖定與追擊 | 點擊魔物；手動方向輸入解除鎖定 |
| 普通攻擊 | 空白鍵或劍形按鈕 |
| 職業技能 | 1–5 或技能快捷鍵 |
| 生命／魔力藥水 | Q／R 或紅／藍藥水按鈕 |
| 拾取 | E、拾取按鈕或點擊地上掉落物 |
| 互動 | 點擊 NPC、傳送門、寶箱或刻印石門 |
| 自動練功 | 在野外切換右下角的「自動練功」 |
| 關閉面板 | Esc 或關閉按鈕 |

角色上限為 50 級。保留 V1.0 八個區域，新增灰港要塞、沉星遺跡、蒼龍谷與兩層深淵迴廊。共 13 個區域、51 種魔物、10 名區域魔王及 1 名世界魔王。五種職業共有 25 種技能。九個裝備欄位與六種品質組成 54 組基本裝備，另有職業武器、隨機屬性及 13 種消耗品／材料。強化最高 +15，武器至 +6、防具至 +4 為安全範圍。任務簿含 53 個委託，另有成就、稱號、魔物圖鑑、六種變身及三個職業召喚生物。

### V2.0 遠征

從燼燈村的小地圖傳送至灰港要塞。遠征任務會逐步指引玩家進入沉星遺跡、蒼龍谷與兩層深淵迴廊。點擊任務的「導航」可前往同區域的目標，或開啟通往其他區域的入口。野外裂隙每天可淨化一次，擊退兩名守衛即可取得遺物；二層祭壇的蝕月皇會預警十字和外環攻擊。在野外使用瞬間移動卷軸可嘗試跳至附近的安全位置。

背包可比較同一欄位的裝備。鑑定後，附有屬性或吸血的武器及飾品會顯示其效果；使用附屬性武器可對弱點造成更多傷害。灰港神秘商人也出售該地獨有的遺物。

V2.2 提供標準、高畫質與極致畫質，以及標準、大字體和特大字體。高畫質依裝置像素比和像素預算選擇繪圖緩衝尺寸。持續幀率不足時會降低繪圖解析度，重新選擇畫質可重試原設定。背景音樂、戰鬥音效和環境音效可分別調整。iPhone 或 iPad 建議橫向，並從 Safari 分享選單加入主畫面，以減少瀏覽器工具列占用空間。遊戲使用內建 Noto Sans TC，原創美術、配樂和授權資訊見 [素材清單](ASSETS.md)。

戰鬥、裝備、任務和探索進度儲存在目前瀏覽器的 localStorage。遊戲會定期自動存檔，設定也提供手動儲存、匯出與匯入。使用另一台裝置、瀏覽器或網站來源時，可透過 JSON 檔移轉角色。V2.0 使用相同的儲存鍵，可直接讀取 V1.0 的進度和 JSON，並以預設值補齊新設定。切換區域時會清除地面戰利品並重建魔物。重新載入也會重置戰鬥狀態、召喚及變身時效。

## 檢查與測試

```sh
npm run check
npm test
npm run build
npm run preview
```

瀏覽器整合測試在開發或預覽伺服器執行期間，從另一個終端啟動。

```sh
npx playwright install chromium
npm run test:browser
npm run test:presentation
```

已有 Chromium 時，可設定 `SHADOW_CHROMIUM=/path/to/chromium`。若要測正式版本，將 `SHADOW_TEST_URL` 指向預覽伺服器（預設測試開發伺服器的 5173）。整合測試涵蓋桌面輸入、行動觸控、購物、強化、任務、戰鬥掉寶及讀檔。

## GitHub Pages 部署

1. 在 GitHub 儲存庫的 **Settings → Pages → Build and deployment** 選擇 **GitHub Actions**。
2. 合併開發分支至 `main`，或在 `main` 上從 **Actions** 手動執行「建置與部署 GitHub Pages」。
3. 成功後，從部署工作或 **Settings → Pages** 開啟站點。此儲存庫的預定網址為 `https://kaya789142-alt.github.io/shadow-dungeon/`。

工作流程執行單元測試並發布 `dist/`，部署後會從正式網址比對 Git 提交、建置識別碼和關鍵資源。相對資源路徑、PWA manifest 和服務工作程式均支援專案子路徑。首次成功載入後，服務工作程式預先快取遊戲、美術和字體，以供離線遊玩。每次啟動或回到頁面都會檢查更新；啟用另一個已驗證的建置時會先儲存角色，再重新載入。首次從 V2.1 的舊 PWA 升級時，讓有網路的頁面完成資源安裝後再重新開啟。若仍看到舊版，以相同網址加上 `?refresh=1` 開啟即可重新導覽，原有存檔會一起載入。可在首頁及設定比對建置 ID，也可查看正式站的 `release.json`。配樂於切換場景時串流載入，離線仍可遊玩及使用內建操作音效。

## 專案結構

- `src/data.ts` 管理職業、技能、區域、魔物、道具、委託與機率。
- `src/model.ts` 管理角色成長、背包資料、裝備機率、任務進度及版本化存檔。
- `src/world.ts` 管理 Phaser 地圖、移動、仇恨、戰鬥及即時效果。
- `src/main.ts` 管理繁體中文介面、輸入、商店與遊戲流程。
- `src/art.ts` 與 `src/sound.ts` 使用程式產生原創地圖及 Web Audio 音訊。
- `src/portrait-sprites.ts` 載入角色圖與動作圖集，`src/world-text.ts` 以獨立 HTML 呈現場景名牌和傷害。
- `src/release.ts` 和 `scripts/pwa.mjs` 管理建置識別、資源版本和先存檔再更新。

職業與區域為獨立資料定義。未來的轉職可沿用角色成長與技能定義；多人版可把目前場景的戰鬥狀態搬到權威伺服器，再由客戶端接收狀態並渲染。雲端存檔可沿用現有版本化 JSON 結構。本版採本機單人遊戲。

另見 [版本變更紀錄](CHANGELOG.md) 與 [V2.2 驗證紀錄](docs/v2.2-verification.md)。
