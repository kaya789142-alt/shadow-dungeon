# V3.0 驗收

## 比對基準

建立分支時遠端 `main` 為 V2.1 合併提交 `263333c`，V2.2 尚未合併。本分支先納入已推送的 V2.2 功能，畫面比較以 V2.2 的實際遊戲建置為升級前基準。正式站主機的存取在此前的雲端環境曾回覆 403，合併和部署以 GitHub 上的實際狀態為準。

## 驗收指令

- `npm run check`、`npm test`、`npm run build`。
- `npm run test:v30` 驗證功能視窗與側欄收合、背包分類、比較、排序、跨區回走、舊座標、滿包、鎖定與拾取防重複。
- `npm run test:browser` 與 `npm run test:presentation` 驗證舊進度、桌面與行動操作、iPad 橫向模擬、字級、Retina、畫質和原有音樂。設定 `SHADOW_TEST_OFFLINE=1` 可驗證離線重開。
- `node test/memory.mjs` 在觸控裝置設定下反覆傳送，觀察地圖快取上限與 Chromium JavaScript heap。
- `node test/update.mjs` 接受舊版、目前版與下一個建置的正式輸出目錄。在同一子路徑測試不完整發布、存檔、版本切換和離線重開。

## 範圍與限制

地圖分為燼燈村至黑暗魔王城堡，以及灰港至深淵兩條走廊。兩條走廊間沿用傳送。相鄰區域會先繪製地圖圖像，玩家跨過接縫時啟用該區域事件與怪物。八方向採既有的正背視角、鏡像與姿勢動畫，騎士有專用圖集。武器和護甲變更以光效呈現。

實機 iPad／iPhone Safari、電量與熱負載須以實機驗證。Chromium 的裝置模擬和 JavaScript heap 僅提供本環境的比較數據。
