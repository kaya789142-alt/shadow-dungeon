## 待審查與部署

本次調整 `scripts/verify-release.mjs`，由下載少數資源改為逐份核對內容。資源回應成功但混入舊版圖集、同名錯誤檔案或 HTML 時，檢查會失敗。GitHub Actions 照原流程在 main 發布，並使用預期的 Git 提交、版本、建置識別碼及發布後資源檢查。

Git transport 可列出 PR #1、#2 的 refs，沒有 V3.1 整合分支的對應 refs。GitHub PR 與 Actions API 在本環境回覆 HTTP 403，正式網址的 `release.json` 也回覆 403。main 的合併、正式部署及 CDN 驗收等待使用者核准及可用權限。 [GitHub 比較頁](https://github.com/kaya789142-alt/shadow-dungeon/compare/main...release/shadow-dungeon-v3.1-integrated?expand=1)

| --- | --- |

| 世界地圖與相鄰步行 | 13 區路網連通性、雙向跨區及連續兩次接縫銜接。維持一個遊戲畫布。 |

## 本輪實測結果

| 驗證 | 結果 |
| --- | --- |
| 安裝、TypeScript、單元、正式建置 | `npm ci` 使用工作環境可寫入的快取重新安裝。13 項單元測試、型別檢查、正式建置通過。Vite 保留既有大分塊提示。 |
| 實際遊戲 | `test:browser`、`test:v30`、`test:v31` 通過。1194×834 橫向全螢幕，預設及單開六個面板的未遮蔽區為 81.7% 至 81.8%。 |
| 美術、字型、音訊 | `test:presentation` 通過。檢查高解析度場景素材、缺圖時保留存檔、繁中字級、七種配樂、手勢續播及關閉環境音後的戰鬥採樣播放。 |
| 效能取樣 | 90 秒自動練功擊殺 70、金幣累計 1,591，平均約 58 FPS，26 次畫面間隔超過 34 ms。十次換區保留最多兩張地圖紋理，JS heap 約 6.20 至 7.36 MiB。 |

| Pages 發布檢查 | 本機正式子路徑版本、提交、首頁、Worker 和 78 份素材全數通過。故意替換圖集、仍回傳 HTTP 200 時驗證失敗。 |
