# 暗影地下城 V3.1 測試報告

本機正式建置以 `/shadow-dungeon/` 提供。使用 Linux Chromium 與 Playwright，平板配置為 iPad Pro 11 橫向 1194×834 CSS px，DPR 2。以下數字為本次樣本。

| 檢查 | 結果 |
| --- | --- |
| `npm run check`、`npm test`、`npm run build` | 通過，13 項單元測試全數通過。Vite 仍有分塊大於 500 kB 提示。 |
| `npm run test:browser` | 通過。桌面、手機橫直向、平板橫向，建立角色、戰鬥、任務、交易、強化、讀檔、觸控與離線重載。 |
| `npm run test:v30` | 通過。裝備比較與分類、滿包保留掉落、自動與手動拾取、鎖定出售、重複拾取防護、V2.2 位置讀取以及雙向步行。 |
| `npm run test:v31` | 通過。八方向輸入、五職業新步行／攻擊圖格、聖騎士施法格。燼燈村經灰港連走到森林，保留原 Canvas。六種面板可開啟、縮小、收合、還原與關閉。以 HUD 矩形聯集計算，初始未遮蔽 81.7%，任一主要面板開啟時 81.8%。 |
| `npm run test:presentation` | 通過。Noto Sans TC、Retina、畫質／字級與全螢幕、NPC 觸控。首頁、村莊、森林、墓園、地下城、戰鬥及魔王 AAC 在瀏覽器播放，暫停後觸控恢復。靜止場景瀏覽器回呼約 61 FPS。 |
| `node test/update.mjs <V3.0> <V3.1-A> <V3.1-B>` | 通過。相同子路徑完成舊快取升級、拒絕混雜的部署內容、保留裝備和存檔、啟用下一建置及離線重載。 |
| `node test/memory.mjs` | 十次換區均保留最多兩張地圖紋理。起始 JS heap 6.27 MiB，峰值與最後樣本 7.40 MiB。實體 GPU 記憶體未測。 |
| `node test/soak.mjs` | 90 秒自動練功擊殺 64 隻，金幣累計 1,505。平均約 55 FPS，91 個畫面間隔超過 34 ms。此樣本使用瀏覽器動畫回呼。 |

下列比較使用兩份正式建置在相同 1194×834 解析度下拍攝，版面並排時等比例縮小。戰鬥固定相同區域、職業及起始存檔座標並在攻擊時拍攝。

- 燼燈村全景、背包、村莊東路與橫向全螢幕。[場景與介面比較](evidence/v31-world.jpg)
- 五職業在幽暗森林的攻擊畫面。[職業攻擊比較](evidence/v31-combat.jpg)

iPad 和 iPhone 的原生 Safari、GPU 記憶體、長時間溫度及耗電沒有實機結果。角色的完整八向獨立動作圖集、全部 NPC／怪物／場景素材的逐一重製及各裝備部位的外觀切換仍有缺項。逐項狀態請見[需求稽核](../REQUIREMENTS_AUDIT.md)。
