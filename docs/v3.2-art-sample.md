## 原創遊戲素材與渲染

- **燼燈村**　重製旅店、石砌房舍、鍛造工坊、噴水池、老橡樹、拱門。屋舍與近景樹木按接地點排序，角色在屋後時會適度淡化遮蔽物。磚路、火把、動態水流和原有行走路徑繼續運作。模型碰撞沒有隨插畫輪廓任意改動。
- **幽暗森林**　新狼與樹人首領圖像接入魔物造型判斷。騎士站立、步幅、收步和出招都以八方向獨立素材呈現，走跑用不同播放節奏。斬擊邊緣加亮，火球與冰霜改用不同的彈道及命中效果。原有效果開關、傷害及掉落規則保留。
- **裝備紙娃娃**　十個部位採原創高解析度物件，裝備疊圖和遊戲人物共用同一圖集。戰鬥幀依手部錨點放置武器。紙娃娃及正向姿態可顯示所有部位，背向有遮住的細小裝備。以實際卸下和重新裝備副手核對渲染及攻防數值。

## 技術界線

Phaser 3 的 Canvas 渲染與現有地圖串流保留。動畫圖集只保留裁切後的有效區，仍以 Retina 繪圖緩衝顯示。現有 Canvas 支援預繪光影、透明前景與排序。參考圖若要求動態材質反射或精確骨架蒙皮，則可在維持戰鬥與存檔邏輯下，使用 WebGL 材質或逐幀繪製並為每幀標記武器和裝備錨點。

**缺項**　騎士出招目前各方向只有一個獨立出招格，施法、死亡仍沿用既有圖格及過渡，受傷以新站姿加短暫退讓。其他職業與美術地圖的全面重製屬第二階段。尚未為所有動作、裝備組合繪製專用遮罩，騎士底圖的基礎衣甲保留。未擷取 iPad Safari 實機 FPS 或畫質，使用者的既有 V3.2 驗收不等於本分支已在實機通過。美術是否達到使用者參考品質待審查。

## 可操作預覽

從第一階段分支執行 `npm ci`、`npm run build` 和 `npm run preview`，在本機開啟 Vite 顯示的預覽網址。另有同版本預先建置的本機預覽包，包含 Python HTTP 啟動程式與獨立樣板角色。開始後可在燼燈村打開裝備測試卸下副手，再用地圖步行至幽暗森林。本機預覽使用獨立網頁來源的儲存區。

## 測試紀錄

- TypeScript、15 項單元測試與正式建置通過。Vite 仍有既有大分塊提示。
- Chromium 實際遊戲測試 `test:browser`、`test:v30`、`test:v31`、`test:v32`、`test:presentation`、`test/polish.mjs` 通過。涵蓋舊 V1／V2.2 進度、多角色管理、觸控、跨區、技能、商店、裝備、背包、交易鎖定、自動拾取與滿包留在地面。
- `test/art-sample.mjs` 驗證實際請求成功 14 份新素材。雙方畫布皆為 1194×728 CSS px、2143×1307 繪圖緩衝，整張照片為 1194×834。騎士方向圖集為 1840×2585、32 格，裝備圖集為 1600×640。新素材 WebP 與 JSON 共約 1.8 MiB。
- Service Worker 同版本升級、舊存檔及裝備保留、混合建置拒絕、離線重開通過。十次跨區傳送最多留兩張地圖紋理，JS heap 約 6.00 至 7.55 MiB，該數字不包含 Canvas 紋理。
- Chromium iPad 尺寸下，並行執行測試時，90 秒騎士自動練功取樣平均 rAF 約 46 FPS，204 次畫面間隔大於 34ms。此數字為軟體瀏覽器回呼取樣，實體 iPad 效能未知。
- 同一 Linux Chromium、騎士與場景的單獨 32 秒對照，原版約 58 FPS，樣板約 59 FPS，超過 34ms 的間隔分別為 9 次和 7 次。短時取樣反映本環境的負載，不能用來保證效能提升或替代 iPad 實機測量。
