# V3.2 裝備與背包驗收

## 開發基準

遠端 main 為 `263333c`。V2.2 與 V3.0 分別為 `138db57`、`5cfb3c0`，V3.1 開發分支為 `18b1b20`。V2.2 的三筆不同 SHA 提交各有完全相同的檔案樹對應，詳見 [V3.1 整合報告](v3.1-integration.md)。Git 遠端的 PR #3 head 為 `602c24b`，其完整程式碼及紙娃娃更新已作為 V3.2 基準。遠端 PR #3 的測試合併 ref 存在，main 尚未含 PR #3 的提交。PR API、Actions 紀錄與正式站 release.json 查詢均收到 HTTP 403，正式部署內容未驗證。

## 需求驗收

| 需求 | 結果與證據 |
| --- | --- |
| 十部位紙娃娃、職業限制與屬性 | 主武器與副手、頭盔、盔甲、手套、腰帶、靴子、披風、項鍊、戒指。測試以滑動與點擊操作切換部位、比較、穿戴及卸除腰帶，讀取更新後的戰力與存檔。主武器維持原有職業限制，防具和飾品維持全職業。 |
| 裝備外觀 | 紙娃娃中央依五職業立繪顯示十部位向量圖層，隨穿戴及品質更新。原有插畫底圖包含職業武器和衣裝。地圖上的角色動作仍以既有動畫為主，所有裝備的完整逐格重繪未完成。 |
| 防具、飾品與取得 | 腰帶可向防具商人購買。保留原有掉落部位機率，自動拾取仍透過同一背包和堆疊機制。 |
| 出售 | 已驗證單件、多選、整批品質及堆疊道具出售。成交前顯示件數、總價及裝備清單。多選測試成交 55 金幣，稀有裝備二次確認後成交 62 金幣。重複結算及報價後鎖定均由單元測試拒絕。穿戴、鎖定及任務道具受保護。 |
| 背包及排序 | 包含全部、武器、防具、飾品、消耗品、材料、魔法卷軸、任務道具。品質、階級、售價、取得時間依裝備及道具組別排序。沒有舊版時間資料的物品維持原順序。快速使用、堆疊、鎖定及比較沿用既有入口。 |
| 原有遊戲與存檔 | V1、V2.2 存檔回歸，開啟缺少新欄位的舊角色資料及以原本鍵值保留進度。V3.1 至 V3.2 的快取、混合版本拒絕、裝備保留及離線重開已驗證。新腰帶只由支援第十欄的版本讀取。 |
| Retina、繁體中文、操作 | Chromium iPad Pro 11 橫向及 iPhone 13 模擬通過。折疊面板、Noto Sans TC、Retina 及七種配樂與戰鬥採樣沿用並回歸。iPad／iPhone Safari 實機未驗證。 |
| 正式部署 | 維持既有 Pages 工作流程、正式網址及專案子路徑。正式環境驗收待審查與合併。 |
