# V4.0 動作接續驗收

基於 `2458be7` 及上次中斷時的工作區，沿用已生成的八份原創圖稿。本輪沒有重新生成。圖稿整理為 `public/art-motion/` 內八套 WebP／JSON 圖集，共 80 個圖格。已有的騎士與 V3.1 圖格留在原分支。未改版本、經濟數值、角色存檔格式或部署工作流程。

| 角色 | 實際已接入 | 待補 |
| --- | --- | --- |
| 騎士 | 八方向站立、步幅、收步、出招；既有正向施法、受傷及倒地；武器與十欄裝備由當前動作定位 | 方向化連斬、不同武器攻擊與所有消耗品、格擋等獨立動作 |
| 妖精 | 八張分方向步行格；備箭、拉弓、放箭、復位四個動作格；原有施法、受傷與死亡接續 | 各方向的完整步態、跑步及動作循環 |
| 法師 | 八張分方向步行格；法杖聚魔、蓄力、釋放、回復四格，接上普攻及施法；沿用既有受傷與死亡 | 各法術的整套獨立逐幀動作 |
| 暗影刺客 | 八張分方向步行格；雙刃起手、蓄勢、橫掃、收招；沿用既有施法、受傷與死亡 | 各方向整套動作與更多專屬技能格 |
| 聖騎士 | 八張分方向步行格；戰鎚起手、抬鎚、落鎚、復位；沿用既有施法、受傷與死亡 | 獨立治癒、盾擊、跑步及完整八向動作循環 |
| 其他四職業裝備 | 盾牌跟隨當前人形圖格的尺度、定位、翻面及上下層；動作鏡頭不隨移動鍵任意轉向 | 基礎武器／衣裝已繪入立繪，尚無每套衣甲獨立換裝圖 |
| 10 名 NPC | 各兩張原創工作動作，依職業定時播放並由對話觸發。鍛造師有錘擊火花 | 完整獨立待機、眨眼及交談循環 |
| 灰脊狼人和苔冠貝希摩 | 狼有四足步態、蓄伏、撲擊、受傷和死亡；首領有步行、抬臂、拍擊、受傷、施法和崩倒 | 其他魔物與首領沿用既有動作。全套獨立動作及首領各階段仍待製作 |

近戰判定在出招命中格執行，遠程先播發射姿勢，再於既有彈道抵達時判定。技能在施法釋放時執行，彈道型技能在抵達時執行傷害。跨區與玩家死亡會清除待判定事件。一般移動在動作發出期間暫停，以避免持續滑動。
