# V4.0 暗黑史詩版開發驗收

## 基準與回復

已讀取 [Issue #6](https://github.com/kaya789142-alt/shadow-dungeon/issues/6) 的公開描述。遠端 main `4816e93` 已合併 PR #5，包含 V3.2 美術樣板。以該提交建立 `feat/shadow-dungeon-v4.0`，另建本機 `backup/v3.2-before-v4` 和經 `git bundle verify` 驗證的完整 Git bundle。Git 回復點包含原始碼及歷史，玩家的瀏覽器資料繼續使用原有存檔鍵和格式。正式站版本及 Actions 工作在此環境回覆 HTTP 403。

## 本輪遊戲改動

- 燼燈村與森林以飄散草地、泥土區塊和變化石板補充原本的地面材質。戶外有日夜循環、細雨和薄霧，效果量受畫質與效能降級控制，保留既有前景、流水和火把。
- 延續騎士的八方向獨立站立、步幅、收步與出招圖格。加入正向施法、受擊及死亡各兩個原創過渡格，沿用裝備疊圖。步行與跑步速度、循環節奏及腳步音依表面區別。
- 裝備盾牌可格擋，格擋有聲光與傷害文字。普通魔物先顯示攻擊預警，預警期間可離開距離、利用障礙或冰凍打斷。自動練功暫時跳過無法接近的目標。
- 實際新增亡靈地監兩層與魔龍古堡。保留舊區域 ID，新增等級門檻、步行串流、陷阱、十二種怪物及首領。魔龍使用擴張吐息預警，首領裝備掉落下限為傳說，新增灰骨誓言、獄鐵王權與焚宙龍鑄三套遺物。
- 三件同系列加防禦 4，五件加物攻及魔攻 5。裝備頁和比較共用實際角色運算。既有商店、強化、品質、掉寶、等級與金幣資料保留。

## 驗收

- 16 項單元測試、TypeScript 和正式建置通過。Vite 仍提示既有分塊大於 500 KB。
- Linux Chromium 驗證桌面、手機直橫向、iPad 橫向模擬的觸控、調整與戰鬥。V1／V2.2 舊存檔、跨區、既有技能、商店、強化、背包滿包、裝備交易及多角色持續通過。
- `test/epic.mjs` 在 1194×834 模擬中以實際操作確認五件套裝及施法，傳至亡靈地監一層，接著步行跨層及前往魔龍古堡，實際交戰及擊殺。
- [實際遊戲畫面](evidence/v40-gameplay.jpg)包含燼燈村、騎士施法、亡靈地監和魔龍古堡。

## 缺項與上線狀態

其他四職業、怪物和所有視角的完整逐格動作與穿戴材質仍待美術製作。新地監與古堡的主要地圖素材沿用適用的原創圖集，缺少完整的獨立場景素材組。跑步共用步態圖格並調整節奏。首領新增吐息和傳說戰利品以遊戲邏輯為準，本輪未完成魔龍個體完整擊殺及所有掉落組合的長時間驗收。經驗值與金幣經濟的全面調校仍待長時間取樣。

WebKit 下載遭環境 HTTP 403，iPad Safari 實機與原生合成效能未驗證。main 及既有 Pages 工作流程保持原狀。正式 V4.0 部署需先取得合併授權，且驗證 Actions 與部署版本。

PWA 從 V3.2 升級、混合快取拒絕、新建置接手及離線重開通過。58 秒騎士自動練功樣本擊殺 35 次，平均 rAF 約 58 FPS，25 個間隔超過 34ms。這是連續遊戲的 Chromium 尺寸模擬取樣。
